# 单次股票交易：标准题解

## 题目与来源

最多买卖一次且先买后卖，求最大利润，允许不交易。

来源参考：https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：贪心、数组

## 算法思路

扫描时维护历史最低价格，以当前价格卖出的利润减去最低买入价，取最大值。

## 正确性说明

任意卖出日的最优买入日一定是此前最低价日，扫描所有卖出日就穷尽所有候选。答案初始 0 覆盖不交易。

## 复杂度

O(n) 时间，O(1) 额外空间。

## 边界与易错点

数据约束：1≤n≤200000，0≤价格≤10^9。

回归样例除普通情况外包括：

- 输入 `3 / 9 5 1`，期望输出 `0`。
- 输入 `1 / 0`，期望输出 `0`。

## Python 3 参考实现

```python
n=int(input()); a=list(map(int,input().split())); low=a[0]; ans=0
for x in a:
    ans=max(ans,x-low); low=min(low,x)
print(ans)
```
