# 爬楼梯计数：标准题解

## 题目与来源

每次爬 1 或 2 级台阶，求到达第 n 级的方法数，对 1000000007 取模。

来源参考：https://leetcode.cn/problems/climbing-stairs/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：动态规划、递推

## 算法思路

最后一步来自 n-1 或 n-2，使用滚动变量计算 Fibonacci 型递推。

## 正确性说明

按最后一步分类，两类方案互斥且穷尽。设空路径 f[0]=1，f[1]=1 后递推成立。

## 复杂度

O(n) 时间，O(1) 空间。

## 边界与易错点

数据约束：1≤n≤1000000。

回归样例除普通情况外包括：

- 输入 `1`，期望输出 `1`。
- 输入 `5`，期望输出 `8`。

## Python 3 参考实现

```python
n=int(input()); a=b=1
for _ in range(1,n): a,b=b,(a+b)%1000000007
print(b)
```
