# 整数平方根：标准题解

## 题目与来源

给定非负整数 x，求平方不超过 x 的最大整数。

来源参考：https://leetcode.cn/problems/sqrtx/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：数学、二分查找

## 算法思路

二分第一个平方大于 x 的整数，再减一。其他语言可用除法比较避免乘法溢出。

## 正确性说明

平方函数在非负整数上单调，二分保持答案分界位于区间内，最终定位首个不满足平方上界的位置。

## 复杂度

O(log x) 时间，O(1) 空间。

## 边界与易错点

数据约束：0≤x≤10^18。

回归样例除普通情况外包括：

- 输入 `0`，期望输出 `0`。
- 输入 `1000000000000000000`，期望输出 `1000000000`。

## Python 3 参考实现

```python
x=int(input()); l=0; r=x+1
while l<r:
    m=(l+r)//2
    if m*m<=x: l=m+1
    else: r=m
print(l-1)
```
