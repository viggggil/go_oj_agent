# 两数目标和：标准题解

## 题目与来源

给定整数数组和目标值，输出两个不同元素的下标，使其和为目标值。保证恰有一组解，下标从 1 开始且升序输出。

来源参考：https://leetcode.cn/problems/two-sum/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：数组、哈希表

## 算法思路

从左到右扫描，用哈希表保存已访问值的下标。对 x 查找 target-x，命中后立即返回。先查询再插入，避免重复使用当前元素。

## 正确性说明

处理第 j 项时哈希表包含所有更早元素。唯一答案的第二个下标到来时，其补数必在表中，因此算法必找到且不会使用同一位置。

## 复杂度

期望 O(n) 时间，O(n) 空间。

## 边界与易错点

数据约束：2≤n≤200000，元素及 target 绝对值≤10^9。

回归样例除普通情况外包括：

- 输入 `2 6 / 3 3`，期望输出 `1 2`。
- 输入 `3 0 / -2 5 2`，期望输出 `1 3`。

## Python 3 参考实现

```python
n,t=map(int,input().split()); a=list(map(int,input().split())); seen={}
for j,x in enumerate(a,1):
    if t-x in seen:
        print(seen[t-x],j); break
    seen[x]=j
```
