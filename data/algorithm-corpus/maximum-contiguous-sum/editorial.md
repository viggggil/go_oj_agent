# 最大连续子段：标准题解

## 题目与来源

求非空连续子数组的最大元素和。

来源参考：https://leetcode.cn/problems/maximum-subarray/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：数组、动态规划

## 算法思路

维护以当前位置结尾的最大和 cur=max(x,cur+x)，同时更新全局答案。必须从首元素初始化。

## 正确性说明

以 i 结尾的最优区间要么仅含 a_i，要么延伸以 i-1 结尾的最优区间，递推穷尽两种情况。对所有终点取最大得到全局最优。

## 复杂度

O(n) 时间，O(1) 额外空间。

## 边界与易错点

数据约束：1≤n≤200000，|a_i|≤10^9。

回归样例除普通情况外包括：

- 输入 `3 / -5 -2 -8`，期望输出 `-2`。
- 输入 `1 / 0`，期望输出 `0`。

## Python 3 参考实现

```python
n=int(input()); a=list(map(int,input().split())); cur=ans=a[0]
for x in a[1:]:
    cur=max(x,cur+x); ans=max(ans,cur)
print(ans)
```
