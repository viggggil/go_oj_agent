# 快速幂取模：标准题解

## 题目与来源

计算 a 的 b 次方对 p 取余，约定零次幂为 1。

来源参考：https://www.luogu.com.cn/problem/P1226。以下讲解、参考代码与测试数据为本项目编写。

算法标签：数论、快速幂

## 算法思路

按指数二进制位处理，位为 1 时乘入当前底数，每轮底数平方、指数减半。

## 正确性说明

保持 ans·base^remaining 与原幂同余，处理奇偶指数均保持不变量；指数归零后 ans 即答案。

## 复杂度

O(log(b+1)) 时间，O(1) 空间。

## 边界与易错点

数据约束：0≤a,b≤10^18，1≤p≤10^9。

回归样例除普通情况外包括：

- 输入 `0 0 7`，期望输出 `1`。
- 输入 `7 5 1`，期望输出 `0`。

## Python 3 参考实现

```python
a,b,p=map(int,input().split()); a%=p; ans=1%p
while b:
    if b&1: ans=ans*a%p
    a=a*a%p; b//=2
print(ans)
```
