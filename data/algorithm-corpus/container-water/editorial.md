# 盛水容器：标准题解

## 题目与来源

选择两条竖线，容量等于下标距离乘以较低高度，求最大容量。

来源参考：https://leetcode.cn/problems/container-with-most-water/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：双指针、贪心

## 算法思路

双指针从两端开始，记录面积后移动较矮的一端。

## 正确性说明

固定较矮端并缩短宽度，较低高度不可能变大，所以不会得到更优解；可以安全舍弃较矮端。逐步排除后必保留某个最优解。

## 复杂度

O(n) 时间，O(1) 空间。

## 边界与易错点

数据约束：2≤n≤200000，0≤h_i≤10^9。

回归样例除普通情况外包括：

- 输入 `2 / 0 9`，期望输出 `0`。
- 输入 `3 / 5 5 5`，期望输出 `10`。

## Python 3 参考实现

```python
n=int(input()); a=list(map(int,input().split())); l=0; r=n-1; ans=0
while l<r:
    ans=max(ans,(r-l)*min(a[l],a[r]))
    if a[l]<a[r]: l+=1
    else: r-=1
print(ans)
```
