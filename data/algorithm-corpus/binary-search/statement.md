# 二分查找首个目标

在非递减数组中求 target 首次出现的位置（1 开始），不存在输出 -1。

## 输入与输出

输入 n target 和数组；输出位置。

## 数据范围

1≤n≤200000，|a_i|、|target|≤10^9。

## 样例输入

```text
5 2
1 2 2 3 4
```

## 样例输出

```text
2
```
