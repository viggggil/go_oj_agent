# 数字三角形：标准题解

## 题目与来源

从三角形顶端向下，每次到左下或右下，求到最后一行的最大路径和。

来源参考：https://www.luogu.com.cn/problem/P1216。以下讲解、参考代码与测试数据为本项目编写。

算法标签：动态规划、网格

## 算法思路

自底向上把每个位置改为自身值加两个孩子最优值的最大者。

## 正确性说明

任意路径下一步只能选择两个孩子之一，孩子最优解已知时取最大即为当前最优，逐层归纳到根。

## 复杂度

O(n²) 时间，O(n²) 空间。

## 边界与易错点

数据约束：1≤n≤500，|元素|≤10^6。

回归样例除普通情况外包括：

- 输入 `1 / -7`，期望输出 `-7`。
- 输入 `2 / -1 / -2 -3`，期望输出 `-3`。

## Python 3 参考实现

```python
n=int(input()); a=[list(map(int,input().split())) for _ in range(n)]
for i in range(n-2,-1,-1):
    for j in range(i+1): a[i][j]+=max(a[i+1][j],a[i+1][j+1])
print(a[0][0])
```
