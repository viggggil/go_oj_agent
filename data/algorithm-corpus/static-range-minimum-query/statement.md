# 区间最小值查询

给定不可修改整数数组，回答若干闭区间最小值查询。这是 RMQ 模板的最小值版本。

## 输入与输出

输入 n q 和数组，再 q 行 l r；每行输出区间最小值，下标从 1 开始。

## 数据范围

1≤n,q≤100000，|a_i|≤10^9。

## 样例输入

```text
4 3
3 -1 4 2
1 4
3 4
2 2
```

## 样例输出

```text
-1
2
-1
```
