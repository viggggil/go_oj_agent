# 区间素数计数：标准题解

## 题目与来源

统计 1 到 n 内的素数个数；这是筛法模板的计数版本。

来源参考：https://www.luogu.com.cn/problem/P3383。以下讲解、参考代码与测试数据为本项目编写。

算法标签：数论、筛法

## 算法思路

埃氏筛从每个素数的平方开始标记其倍数，最后统计未标记的大于 1 的数。

## 正确性说明

每个合数都含不超过平方根的素因子，必被标记；素数不会被更小因数标记。小于平方的倍数早已由更小因子处理。

## 复杂度

O(n log log n) 时间，O(n) 空间。

## 边界与易错点

数据约束：1≤n≤2000000。

回归样例除普通情况外包括：

- 输入 `1`，期望输出 `0`。
- 输入 `2`，期望输出 `1`。

## Python 3 参考实现

```python
n=int(input()); prime=bytearray(b'\x01')*(n+1); prime[0]=prime[1]=0
for p in range(2,int(n**0.5)+1):
    if prime[p]: prime[p*p:n+1:p]=b'\x00'*((n-p*p)//p+1)
print(sum(prime))
```
