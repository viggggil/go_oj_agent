# 不相邻元素最大和：标准题解

## 题目与来源

选择若干互不相邻的数组元素，求最大和，可以不选。

来源参考：https://leetcode.cn/problems/house-robber/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：动态规划、数组

## 算法思路

dp[i]=max(dp[i-1],dp[i-2]+a_i)，用两个变量滚动保存。

## 正确性说明

最优方案要么不选第 i 项，要么选它并排除第 i-1 项；两种情况的剩余部分均为更小前缀上的最优问题。

## 复杂度

O(n) 时间，O(1) 额外空间。

## 边界与易错点

数据约束：1≤n≤200000，0≤a_i≤10^9。

回归样例除普通情况外包括：

- 输入 `1 / 0`，期望输出 `0`。
- 输入 `3 / 5 1 5`，期望输出 `10`。

## Python 3 参考实现

```python
n=int(input()); a=list(map(int,input().split())); p=q=0
for x in a: p,q=q,max(q,p+x)
print(q)
```
