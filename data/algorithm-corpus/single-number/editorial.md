# 只出现一次的数：标准题解

## 题目与来源

数组中一个数出现一次，其余每个数出现两次，求单独的数。

来源参考：https://leetcode.cn/problems/single-number/。以下讲解、参考代码与测试数据为本项目编写。

算法标签：位运算、数组

## 算法思路

把所有元素按位异或。

## 正确性说明

异或可交换结合，x xor x=0，0 xor y=y。成对元素抵消，最终仅剩唯一数。

## 复杂度

O(n) 时间，O(1) 额外空间。

## 边界与易错点

数据约束：1≤n≤200001，n 为奇数，0≤a_i≤10^9。

回归样例除普通情况外包括：

- 输入 `1 / 0`，期望输出 `0`。
- 输入 `3 / 7 9 7`，期望输出 `9`。

## Python 3 参考实现

```python
n=int(input()); ans=0
for x in map(int,input().split()): ans^=x
print(ans)
```
